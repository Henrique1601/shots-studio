# 🚀 07_ROADMAP_AND_BACKLOG.md — Roadmap & Próximas Inovações

Planejamento estratégico de evolução para o **Shots Studio**.

---

## 📅 Roadmap de Versões

### 🟢 Fase 1: Paridade Visual & Estúdio Essencial (Concluída - v1.0.0-elite)
- [x] Design System fiel ao Shots.so com dark theme exclusivo.
- [x] 12 Estilos oficiais em grid 3 colunas (Glass, Liquid, Retro, Stack, etc.).
- [x] Catálogo completo de aparelhos incluindo iPhone 17 e iPhone 17 Air com Dynamic Island.
- [x] Pad 3D interativo com captura de rotação física e reset via Custom Layout.
- [x] Fórmulas de sombra multi-camada adaptativa e ajuste de luz especular.
- [x] Carrossel multi-slide com download em ZIP em até 6K.
- [x] Linha do tempo de animação integrada (Turntable, Float, Pulse, Orbit).

---

### 🟡 Fase 2: Motor Serverless de Renderização de Vídeo (v1.1.0)
- [ ] Pipeline de renderização em nuvem via Remotion Lambda para exportação de arquivos `.mp4` e `.webm` em 60fps sem sobrecarregar a CPU do cliente.
- [ ] Integração com efeitos sonoros de transição e click nos mockups.
- [ ] Exportação em formato GIF otimizado para Twitter/X e LinkedIn.

---

### 🔵 Fase 3: Comunidade & Sincronização em Nuvem (v1.2.0)
- [ ] Sincronização opcional com Supabase / Neon Postgres para salvar templates pessoais do usuário na nuvem.
- [ ] Galeria comunitária aberta para compartilhamento público de links de mockups prontos.
- [ ] Extensão para Google Chrome para captura de telas com 1 clique diretamente para dentro do Shots Studio.
